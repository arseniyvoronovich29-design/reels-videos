# reels-videos — еженедельные ролики «что будет с телом, если…» для TikTok @rehsuktt

Владелец: Арсений. Общаться с ним по-русски, коротко, без технических подробностей.
Он хочет максимальной автоматизации: всё делает Claude, от него нужно только «да» раз в неделю.

## Главное правило
**Ничего не публиковать без явного «да» Арсения.** Все посты в Metricool сначала создаются черновиками (`draft: true`).
Только после его «да» в том же чате/задаче черновики переводятся в автопубликацию (`draft: false`, `autoPublish: true`).

## Расписание
- Каждый вторник (запланированная задача, ~11:00 по Новосибирску) Claude делает **5 роликов** на ближайшие **среду–воскресенье**.
- Публикация: каждый день ср–вс в **23:00 Asia/Novosibirsk**, TikTok, один ролик в день.
- Лимит бесплатного Metricool — 20 постов в месяц. Перед постановкой проверь, сколько постов уже стоит в этом месяце
  (`getScheduledPosts` за месяц); если пятёрка не влезает — поставь сколько влезает и скажи Арсению.

## Еженедельная процедура
1. **Темы.** Придумай 5 новых тем. Сверься с `topics.json`: поле `done` (уже сделано), `avoid` (идеи из чужих референсов
   и отклонённые Арсением), `backlog` (можно брать). Повторять нельзя. Нужна тревога и «не по себе»: крики, обратный отсчёт,
   поворот сюжета (ложное улучшение, срыв спасения и т. п.). Темы про организм: что происходит с телом.
2. **Факты.** Для каждой темы найди 2–4 надёжных источника (WebSearch/WebFetch). Пиши в ролик только проверенные факты,
   спорные цифры заменяй словами, иллюстративные значения помечай «≈». Источники — комментарием в начале `spec.py`.
3. **Ролик = spec-файл.** `weeks/<дата среды>/<n>_<slug>/spec.py` по образцу `weeks/2026-11-04/*/spec.py`.
   Формат (обязательно): ~45–55 с; первый кадр — крупное испуганное лицо + жёлтый заголовок «…» + красная плашка «что будет с телом?»;
   смена сцены каждые 2,5–3 с; таймер, ЭКГ и пульс внизу; рентген с подписями органов; клеточная схема; большая цифра;
   карточка «МИФ»; «ФАКТЫ — ПРОВЕРЕНО» из 5 пунктов; в конце переход-петля к первому кадру.
   Звук синтезируется автоматически (крики, сердце, удары на склейках, гул) — события добавляй в `sfx`.
4. **Проверка.** `cd tools/sim && python3 engine.py check ../../weeks/<…>/spec.py` → посмотри `sheet.png` (Read):
   текст в безопасной зоне (не правее x=940, не ниже y=1560), персонаж виден, ничего не налезает, лицо не обрезано.
   Исправь и проверь снова.
5. **Рендер.** `python3 engine.py render ../../weeks/<…>/spec.py` (в фоне, timeout 7200000; машина 2 ядра — рендерь по одному).
   Получится `<slug>.mp4`. Проверь: длительность, громкость (`ffmpeg -af volumedetect`, mean ≈ −14…−19 дБ),
   кадры из готового mp4 (контактный лист через ffmpeg).
6. **Публикация в репозиторий.** `git add weeks/<…> topics.json && git commit && git push origin main`
   (сначала `git fetch origin main` и rebase). Ссылка для Metricool:
   `https://raw.githubusercontent.com/arseniyvoronovich29-design/reels-videos/main/weeks/<…>/<slug>.mp4`
   Перед постановкой проверь, что ссылка отдаёт видео (WebFetch или curl -I может не пройти через прокси — тогда просто ставь, Metricool сам скачает).
7. **Metricool (черновики).** brand/blogId `7840647`, timezone `Asia/Novosibirsk`, provider `tiktok`.
   `createScheduledPost` с `info`: `draft: true`, `autoPublish: true`, `media: [raw-ссылка]`, `text: caption + хештеги`,
   `publicationDate: {dateTime: "YYYY-MM-DDT23:00:00", timezone: "Asia/Novosibirsk"}`,
   `tiktokData: {privacyOption: "PUBLIC_TO_EVERYONE", title: <название>, isAigc: true}`.
   Если на эту дату уже есть старый черновик — обнови его (`updateScheduledPost`) вместо создания нового.
   Запиши id/uuid постов в `weeks/<…>/week.json`.
8. **Показать неделю.** Отправь Арсению (SendUserFile) все 5 mp4 и сообщение: даты, названия, описания, хештеги, источники кратко.
   Можно опубликовать страницу-превью недели (Artifact). Попроси ответить «да» или указать, что поменять. Жди.
9. **После «да».** Для каждого поста недели: `updateScheduledPost` с тем же содержимым и `draft: false`. Проверь `getScheduledPosts`,
   что статусы стали запланированными. Сообщи Арсению одной строкой. Добавь темы недели в `topics.json` → `done`.

## Описание и хештеги
- Описание: 1–2 строки, интрига + вопрос в конце для комментариев, 1 эмодзи 😨 и 👇.
- Хештеги: ровно 5, релевантные: тема, ещё одна по теме, `#чтобудетесли #симуляция #организм`.

## Техника
- Движок: `tools/sim/engine.py` (сцены, рентген, клетки, цифры, миф, факты, HUD), `tools/sim/sound.py` (саундтрек),
  `tools/sim/base.py` (персонаж, лица, подписи), `anatomy.py`, `pose.py`, шрифты Inter в `tools/sim/fonts`.
- Виды сцен в spec: `face`, `scene` (пресеты forest kitchen beach sea bedroom street office hospital night), `xray`, `micro`
  (liver neuron lung muscle blood), `bignum`, `flat` (остановка сердца), `black`, `myth`, `facts`, `loop`, `custom` (своя функция рисования).
- Зависимости: python3, numpy, pillow, scipy, ffmpeg (есть в окружении).
